## Purpose

Provides users with the ability to switch between light and dark visual themes for improved accessibility and comfort.

## ADDED Requirements

### Requirement: Theme switching
The system SHALL allow users to toggle between a light theme and a dark theme.

#### Scenario: Successful theme toggle
- **WHEN** the user clicks the theme toggle button
- **THEN** the website's visual theme changes to the alternative mode (light to dark, or dark to light)
