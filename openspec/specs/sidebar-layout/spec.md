## Purpose

Keeps the two-column desktop layout visually balanced by sizing the sidebar card to match the main content card.

## Requirements

### Requirement: Sidebar height matches main panel
On desktop viewports, the left sidebar card SHALL render at the same height as the adjacent main content card.

#### Scenario: Equal-height columns on desktop
- **WHEN** the site is viewed at desktop width (md breakpoint and up)
- **THEN** the sidebar card's bottom edge aligns with the main content card's bottom edge
