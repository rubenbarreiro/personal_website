# My Personal Landing Page

A simple portfolio-style landing page built to improve my React(and nowadays, AI) skills.

## Features

- Responsive design for mobile and desktop
- Card-based sidebar layout
- Tab navigation with "About Me" and "Work Experience" sections
- Dark theme styling

## Tech Stack

- [React](https://react.dev/) - UI library
- [Vite](https://vitejs.dev/) - Build tool and dev server
- [TypeScript](https://www.typescriptlang.org/) - Type-safe JavaScript
- [Material UI](https://mui.com/) - Component library with dark theme

## AI Stack

- [OpenCode](https://opencode.ai) - AI coding assistant for development workflow
- [OpenSpec](https://github.com/anomalyco/openspec) - Spec-driven development for planning and tracking changes
- Model: opencode/big-pickle - Used for all code generation and refactoring

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/rubenbarreiro/personal_website.git
cd personal_website
npm install
```

## Usage

```bash
# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linter
npm run lint
```
